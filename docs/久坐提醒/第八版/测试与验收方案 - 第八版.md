# 测试与验收方案-第八版

> **【已锁定】** 锁定日期：2026-05-12。

## 1. 测试概述

### 1.1 测试范围

第八版新增：枢纽「记录活动」「跳过本次」、久坐下一拍重算、统计 JSONL 新 `kind`、主页嵌入简报双序列、活动统计页双序列图、四类合计、图下情绪简报；**全量回归**第七版随笔、标题、主题、双通道提醒与枢纽其余区块。

### 1.2 测试目标

验证与《需求规格说明书-第八版》P0/P1 一致；确认无新增 Tauri 命令情况下统计契约向后兼容。

### 1.3 参考依据（需求规格说明书、系统总体设计、前后端详细设计）

《需求规格说明书-第八版》《系统总体设计-第八版》《前端详细设计（React）-第八版》《后端详细设计（Rust）-第八版》。

## 2. 测试环境与工具

### 2.1 测试环境配置要求

Windows 10/11；Tauri `dev` 或安装包；应用数据目录可查看 `reminder_stats.jsonl`（验证 kind）。

### 2.2 测试工具清单

手动探索测试；`npm run build`；Vitest（`statsBuckets`）；`cargo test`（回归 stats 裁剪等）。

### 2.3 测试数据准备规范

准备启用久坐、至少一条启用规则；可选预置 JSONL 含历史 `sedentary_completed` / `hydration_notified` 以验证分桶迁移正确。

## 4. 专项测试方案

### 4.1 功能测试方案

执行第 3 节；覆盖 `dimension` 全枚举与枢纽双按钮全状态矩阵。

### 4.2 性能测试方案

第八版无独立性能 KPI；可选对比大 JSONL（数千行）切换维度耗时主观可接受。

### 4.3 兼容性测试方案

125% 缩放下枢纽久坐行换行后按钮仍可点、文案不重叠不可读。

### 4.4 安全性测试方案

确认简报无 `dangerouslySetInnerHTML` 或等价 XSS 面；统计 kind 仅来自应用内常量。

### 4.5 可用性测试方案

新用户 5 秒内理解「记录活动」与「跳过本次」差异（可用性走查表勾选）。

## 5. 自动化测试方案

### 5.1 自动化测试范围

`statsBuckets`：`buildDetailBuckets`、`briefLast7DaysActivityStacks`、`aggregateWindowTotals`、`peakActivityMergedBucketLabel`、`queryRangeForDimension`；继承 `quietHours` 与 Rust stats 单测。

### 5.2 自动化测试工具选型

### 5.3 自动化测试脚本设计规范

断言分桶边界（小时桶、日桶）；断言窗口合计对多 kind 混合样本计数正确。

## 6. 缺陷管理规范

### 6.1 缺陷分级标准

阻塞：久坐调度错乱或重复触发；严重：合计与 JSONL 不一致；一般：简报错别字或禁用条件遗漏；轻微：颜色对比度偏低。

### 6.2 缺陷报告规范

含复现步骤、期望/实际、维度、附件 JSONL 片段（脱敏）。

### 6.3 缺陷闭环流程

修复 → 回归 TC8-P0-* → 关闭。

## 7. 测试准入准出标准

### 7.1 测试准入标准

`npm run build` 通过；`vitest` 与 `cargo test` 通过；可启动应用。

### 7.2 测试准出标准

TC8-P0 100% 通过；P1 无未修复阻塞/严重；第七版 P0 抽样回归通过。

### 7.3 上线阻断规则

下一拍不重算、统计 kind 未写入、双序列图误含补水柱、四类合计错误。

## 8. 测试进度与里程碑

### 8.1 测试阶段划分

冒烟（双按钮 + JSONL）→ 统计页全维度 → 第七版回归。

### 8.2 测试里程碑节点

构建候选 → 测试签署准出。

### 8.3 测试进度管控规则

阻塞缺陷当日同步；调度类缺陷优先。
