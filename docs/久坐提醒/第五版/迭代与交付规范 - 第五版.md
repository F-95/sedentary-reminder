# 迭代与交付规范-第五版

> **【已锁定】** 锁定日期：2026-05-09。本文件为久坐提醒第五版基线文档。

## 1. 迭代计划

### 1.1 版本迭代目标

交付久坐提醒第五版：**主界面设置枢纽**（开机启动、久坐/补水下次时间与倒计时、纵向子页入口、分时段单行 Card 标题）；**久坐独立设置页**；**补水 next 前端镜像与主视图秒级时钟**；v2 配置无变更；后端无签名变更。

### 1.2 迭代里程碑节点

| 里程碑 | 说明 |
|--------|------|
| M1 设计冻结 | 七份第五版文档归档 |
| M2 开发完成 | 前端实现、Lint/构建通过 |
| M3 回归完成 | 第四版核心抽样 + 第五版 TC5 通过 |
| M4 发布候选 | RC 构建与 Release Note |

### 1.3 任务拆分与排期

前端独占；后端冒烟确认无命令变更；测试维护 TC5 表。

## 2. 代码管理规范

### 2.1 分支管理规则

建议使用分支名：`久坐提醒-第五版`。

### 2.2 代码提交规范

提交信息包含：`久坐提醒-第五版`、变更关键词、对应设计条目（如「US5-P0-01」）。

### 2.3 代码合并与评审规则

至少一名评审；须确认久坐调度依赖未被枢纽 UI 破坏、补水镜像与定时器同源。

## 3. 构建与打包规范

### 3.1 构建环境要求

与第四版一致。

### 3.2 构建流程规则

版本号在 `package.json`、`Cargo.toml`、`tauri.conf.json` 随发布节奏一致升级（与仓库发布策略对齐）。

### 3.3 打包产物规范

Release Note 说明：主界面枢纽化、久坐独立页、双通道摘要、分时段标题；配置无迁移。

### 3.4 补丁/插件交付适配规则

第五版属核心 UI/IA，默认不拆插件。

## 4. 发布与部署规范

### 4.1 发布流程

标签驱动 CI → Draft Release → 验证 → Publish。

### 4.2 部署环境要求

与第四版一致。

### 4.3 灰度发布规则

可先内测收集枢纽可读性与标题文案反馈。

## 5. 回滚规范

### 5.1 回滚触发条件

秒级定时器泄漏、补水镜像严重误导、久坐 next 被 UI 改动破坏等严重缺陷。

### 5.2 回滚执行步骤

回退至第四版稳定标签；v2 配置完全兼容。

### 5.3 回滚验证标准

第四版 P0 用例通过。
