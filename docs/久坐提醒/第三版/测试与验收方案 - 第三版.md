# 测试与验收方案-第三版

> **【已锁定】** 锁定日期：2026-05-09。本文件为久坐提醒第三版基线文档，禁止直接修改；变更须于新版本目录全套归档。

## 1. 测试概述

### 1.1 测试范围

在第二版测试范围基础上，新增：

- **调度重算边界**：非调度开关（开机自启、提醒结束锁屏、随机文案）变更不得单独导致 next 重算；调度类字段变更仍须正确重算。
- **免打扰折叠 UI**：折叠/展开、摘要格式、禁用段标识、默认展开。
- **触发时配置一致性**：在仅变更非调度字段后，提醒弹出时的文案策略与活动时长与当前界面一致。
- **跨午夜免打扰**：晚间腿/清晨腿命中、离开边界 + 间隔、结束整点左闭右开；与同日内段组合回归。

全量回归第二版 P0/P1 及第一版核心抽样。

### 1.2 测试目标

验证《需求规格说明书-第三版》US3-P0/P1/P2 全部可验证；确保第二版同日免打扰与迁移无回归，跨午夜增量可验证。

### 1.3 参考依据（需求规格说明书、系统总体设计、前后端详细设计）

《需求规格说明书-第三版》《系统总体设计-第三版》《前端详细设计（React）-第三版》《后端详细设计（Rust）-第三版》《测试与验收方案-第二版》。

## 3. 分级测试用例设计

### 3.1 P0核心用例（核心功能场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC3-P0-01 | 提醒启用，已显示下次提醒时间 T | 仅切换开机自启 | T 不变；后端运行时 next 与标签一致 |
| TC3-P0-02 | 同上 | 仅切换提醒结束后锁屏 | T 不变 |
| TC3-P0-03 | 同上 | 仅切换开启随机文案 | T 不变 |
| TC3-P0-04 | 提醒启用 | 修改提醒间隔 | next 按推迟规则更新（含跨午夜配置下仍正确） |
| TC3-P0-05 | 提醒启用 | 修改免打扰总开关或任一段起止/启用 | next 重算并同步镜像 |
| TC3-P0-06 | 启用跨午夜段（如 22:00–06:00）与固定间隔 | 构造候选落入晚间或清晨禁区 | next 为离开禁区整点 + 完整间隔；与自动化用例一致 |
| TC3-P0-07 | 跨午夜段启用 | 候选落在结束整点（如 06:00） | 该整点**不**触发禁区命中，next 与同日内左闭右开一致 |

### 3.2 P1重要用例（重要功能、边界场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC3-P1-01 | 免打扰页存在至少一段 | 折叠该段 | 标题可见 HH:mm-HH:mm 摘要 |
| TC3-P1-02 | 某段 enabled=false | 折叠该段 | 摘要仍在，且可见「已关闭」或等价标识 |
| TC3-P1-03 | 首次进入免打扰页 | 观察各段 | 默认全部展开 |
| TC3-P1-04 | 从托盘切换开机自启或锁屏 | 同 TC3-P0-01/02 | 行为与主界面开关一致，T 不变 |
| TC3-P1-05 | 提醒启用，next 已排程 | 先改间隔再仅改随机文案 | next 反映间隔变更；随机文案变更不再次推动 next 变化 |

### 3.3 P2次要用例（次要功能、异常场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC3-P2-01 | 自动化 | 对摘要格式化纯函数跑单元测试 | 整点、非整点补零；跨午夜摘要（如 22:00-06:00） |
| TC3-P2-04 | 自动化 | `sanitizeQuietHourRange` | `start>end` 保留；`start===end` 修正为同日 1 分钟 |
| TC3-P2-02 | 提醒弹出前仅改随机文案与文案列表 | 等待触发 | 弹出内容与当前开关/列表策略一致 |
| TC3-P2-03 | 提醒弹出前仅改活动时长 | 等待触发 | 倒计时总秒数与当前配置一致 |

## 4. 专项测试方案

### 4.1 功能测试方案

执行第 3 节用例，交叉核对主界面标签、托盘 tooltip（若存在）与后端镜像一致性；视图在主设置与免打扰间切换后行为不变。

### 4.2 性能测试方案

连续折叠/展开 20 段时无明显卡顿。

### 4.3 兼容性测试方案

v2 配置直接启动第三版构建；第二版核心用例抽样通过。历史配置均为同日段，升级后行为不变；新增跨午夜段仅在新保存后出现。

### 4.4 安全性测试方案

无新 invoke；配置仍本地存储。

### 4.5 可用性测试方案

折叠标题在默认窗口宽度下摘要可读；键盘可聚焦折叠头与表单控件（遵循 AntD 默认行为）。

## 5. 自动化测试方案

### 5.1 自动化测试范围

时段摘要格式化、`sanitize`、推迟算法单元测试：包含第二版同日用例全集 + 跨午夜晚间/清晨/结束整点边界用例。

### 5.2 自动化测试工具选型

与仓库一致（如 Vitest）。

### 5.3 自动化测试脚本设计规范

新增用例须命名清晰对应 US3 编号；调度边界用例以手工或 E2E 补充（可选）。

## 6. 缺陷管理规范

### 6.1 缺陷分级标准

在继承第二版标准基础上：

- **P0**：非调度开关导致 next 被重算；或提醒弹出时使用陈旧随机/时长配置；跨午夜推迟错误导致提醒在禁区内触发。
- **P1**：折叠摘要错误、禁用段无标识、默认全展开破坏；跨午夜说明文案误导。
- **P2**：文案提示未更新第三版行为说明。

### 6.2 缺陷报告规范

同第二版。

### 6.3 缺陷闭环流程

同第二版。
