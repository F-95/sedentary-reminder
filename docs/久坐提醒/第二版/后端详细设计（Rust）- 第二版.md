# 后端详细设计（Rust）-第二版

## 1. 设计概述

### 1.1 设计目标

保持第一版后端命令集合与语义稳定；免打扰逻辑完全由前端调度实现；后端继续承担运行时镜像与托盘展示字段同步职责。

### 1.2 设计约束

- 不新增、不修改 Tauri 命令签名（第二版迭代范围内）。
- `ReminderRuntimeState` 字段在第一版基础上不做结构性扩展（免打扰状态仅存前端）。

### 1.3 参考依据（系统总体设计、需求规格说明书）

《系统总体设计-第二版》《需求规格说明书-第二版》《后端详细设计（Rust）-第一版》。

## 2. 后端目录结构定义

### 2.1 目录层级规范

与第一版一致；免打扰不改变模块布局。

### 2.2 各目录职责定义

无新增目录；`commands/reminder.rs` 内 `update_next_trigger` 继续接收前端计算的最终时间与标签。

不变。

## 3. 接口详细设计

### 3.1 接口清单总览

与第一版一致；命令清单无增量。

### 3.2 单个接口详细定义（表格化：请求路径、请求方法、请求参数、响应格式、错误码、权限要求）

#### update_next_trigger（行为兼容性说明）

| 项目 | 第二版说明 |
|------|------------|
| 调用名 | update_next_trigger |
| 请求参数 | `triggerAtMs`：可选 i64；`triggerLabel`：可选字符串 |
| 响应格式 | Result<(), String> |
| 语义变更 | 前端传入的 `triggerLabel` 仍可为人类可读本地时间字符串；当触发被免打扰推迟时，标签文本自然反映推迟后的时刻（由前端格式化） |
| 权限要求 | 同第一版 |

其余命令定义引用第一版表格，全文保持一致。

### 3.3 接口通用处理规则

后端不解析免打扰配置；不信任前端传入的额外字段（前端不得尝试 invoke 未注册参数）。
