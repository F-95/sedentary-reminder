## 2. 全局技术栈规范

### 2.1 固定技术栈与版本号约束

在第八版基线之上增量锁定：

- Tauri `2.0.0`（应用核心）
- React `18.2.0` / Vite `5.0.10` / TypeScript `5.2.2`
- Ant Design `5.12.0`、@ant-design/icons `5.2.6`
- @tauri-apps/api `2.0.0`、@tauri-apps/plugin-notification `2.0.0`
- **@tauri-apps/plugin-updater `2.0.0`**、**@tauri-apps/plugin-process `2.0.0`**
- **tauri-plugin-updater**、**tauri-plugin-process**（与 Tauri 2 生态兼容的次版本号由 Cargo 解析锁定，以 `Cargo.lock` 为准）
- Rust Edition `2021`

### 2.2 依赖版本管理规范

- 语义化版本号必须通过 **`node scripts/version.mjs <semver>`** 同步至 `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`。
- 更新签名私钥 **禁止入库**；公钥写入 `tauri.conf.json` 的 `plugins.updater.pubkey`；私钥仅通过 `TAURI_SIGNING_PRIVATE_KEY`（及可选密码变量）注入构建环境。

### 2.3 跨平台兼容要求

- **Windows**：以 **Windows 10 x64 + 当前或受支持 WebView2** 为主验证基线；在已安装兼容 **WebView2 固定版或可用运行时** 且系统补丁满足厂商要求的前提下，对 **Windows 7 SP1 x64、Windows 8.1** 做尽力兼容（见《需求规格说明书-第九版》风险与前置条件）。
- 其他平台：本迭代不扩展非 Windows 的更新端点验证范围，保留既有行为。

## 3. 全局代码规范

### 3.1 目录结构规范

第九版增量（相对第八版）：`src/utils/appUpdate.ts`（更新检查与安装封装）；`src/pages/HomePage.tsx` 底部栏布局；`src-tauri/keys/*.pub` 可提交示例公钥文件、**`*.key` 已加入 .gitignore**；`scripts/version.mjs` 实现版本同步；`.env.example` 补充签名变量说明。

### 3.2 命名规则约束

与项目规范一致；Tauri 插件权限标识使用官方 **`updater:default`**、**`process:default`**。

### 3.3 代码编写通用规范

- 主界面底部版本栏不得修改根 `ConfigProvider` 主题；分割线颜色使用 Ant Design **Design Token**（如 `colorSplit`）通过 `theme.useToken()` 读取。
- 检查更新失败须用户可读的 **中文错误提示**；发现新版本须 **二次确认** 后再下载安装。
- 全局主题仍仅通过根 `ConfigProvider` 配置。

## 4. 全局权限与安全规范

### 4.1 接口权限通用规则

- 前端调用 `@tauri-apps/plugin-updater` 的 **check / download / install** 等能力前，须在 **capabilities** 中授予 **`updater:default`**。
- 调用 **`relaunch`** 前须授予 **`process:default`**（或等价 allow 集合）。

### 4.2 数据安全规范

- 更新包必须通过 **minisign 公钥** 校验；公钥与 `endpoints` 返回的 **signature** 字段一一对应；禁止关闭签名校验。
- **endpoints** 必须为 **HTTPS**（生产）；开发环境遵循 Tauri 官方对不安全传输的限制说明。

### 4.3 合规性要求

- 更新说明（notes/body）默认来自发布方提供的静态或动态 JSON，**不上传用户本地提醒数据**。
- 若未来变更更新域名或公钥，须走新版本设计与迁移说明，避免用户断更。

## 5. 需求优先级定义

### 5.1 P0 核心需求清单

- 主窗口底部常驻展示 **当前应用语义化版本号**，右侧提供 **刷新形图标**，点击触发 **检查更新**。
- 集成 **Tauri 官方 Updater**：可发现新版本、用户确认后 **下载并安装**，安装完成后 **自动重启**（与官方 Windows 安装行为一致）。
- **版本号单一来源**：三处配置文件与运行时 `get_app_info` 返回值一致。

### 5.2 P1 重要需求清单

- Windows 安装包配置 **WebView2 引导**（downloadBootstrapper 等），降低首次启动白屏风险。
- Vite 生产构建在 Windows 目标下将 **target** 下调至 **chrome90** 以扩大旧 WebView2 覆盖。

### 5.3 P2 次要需求清单

- Win7/8 下若自动更新安装器受限，文档中说明 **手动下载完整安装包** 的兜底路径（不作为代码强制分支验收项，除非需求升格）。
