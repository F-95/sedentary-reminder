## 1. 测试概述

### 1.1 测试范围

第七版新增：主窗口标题、`index.html` 标题、枢纽「作者的哔哔赖赖」入口、`author` 子页展示与返回；**全量回归**第六版主题、统计、双通道提醒与枢纽布局。

验证与《需求规格说明书-第七版》P0/P1 一致；确认无新增后端契约仍兼容。

## 2. 测试环境与工具

### 2.1 测试环境配置要求

Windows 10/11；Tauri 运行包或 `npm run tauri dev`；可选 `npm run dev` 核对 `index.html` 标签标题。

### 2.2 测试工具清单

手动探索测试；`npm run build`；既有 Vitest / `cargo test`（回归）。

### 2.3 测试数据准备规范

无需为随笔准备数据；统计回归可按第六版准备 JSONL 样本。

## 4. 专项测试方案

## 6. 缺陷管理规范

### 6.1 缺陷分级标准

阻塞：启动崩溃或提醒失效；严重：标题错误且无法配置修复；一般：随笔文案与需求不一致；轻微：标点或换行。

### 6.2 缺陷报告规范

含复现步骤、期望/实际、版本、截图（标题栏）。

### 6.3 缺陷闭环流程

修复 → 回归 TC7-P0-* → 关闭。

## 7. 测试准入准出标准

### 7.1 测试准入标准

`npm run build` 通过；桌面可安装或可 dev 启动。

### 7.2 测试准出标准

TC7-P0 100% 通过；P1 无未修复阻塞/严重；第六版核心 TC 抽样回归通过。

### 7.3 上线阻断规则

窗口标题错误、入口缺失、返回失效、提醒主流程回归失败。

## 8. 测试进度与里程碑

### 8.1 测试阶段划分

冒烟（标题+入口）→ 全量手工 → 第六版回归。

### 8.2 测试里程碑节点

构建候选 → 测试签署准出。

### 8.3 测试进度管控规则

阻塞缺陷当日同步；标题类缺陷优先。
