# 前端详细设计（React）-第三版

> **【已锁定】** 锁定日期：2026-05-09。本文件为久坐提醒第三版基线文档，禁止直接修改；变更须于新版本目录全套归档。

## 1. 设计概述

### 1.1 设计目标

落实第三版需求：收紧 `HomePage` 调度副作用的依赖边界，使非调度配置变更不重置已排程的 next；免打扰页以折叠面板展示各段，折叠标题展示标准化时间摘要。

### 1.2 设计约束

- 不修改 `App.tsx` 全局 `ConfigProvider` 主题策略。
- 页面级组件使用 Ant Design 原生 `Collapse` 等组件，禁止深度选择器覆盖 AntD 结构。
- 推迟算法置于可测纯函数模块 `quietHours`：第三版在同日段行为与第二版一致前提下，扩展**跨午夜**命中与离开边界（绝对时间戳 + 整分边界）；并含摘要格式化与清洗规则。

### 1.3 参考依据（系统总体设计、需求规格说明书、后端详细设计）

《系统总体设计-第三版》《需求规格说明书-第三版》《后端详细设计（Rust）-第三版》《前端详细设计（React）-第二版》。

## 2. 前端目录结构定义

### 2.1 目录层级规范

与第二版一致；第三版建议在既有 `quietHours` 工具模块中增加时段摘要格式化导出（名称见第二版共识示意），不强制新建文件。

### 2.2 各目录职责定义

| 路径 | 第三版职责 |
|------|------------|
| pages/HomePage.tsx | 调度 `useEffect` 依赖仅包含调度切片字段与影响暂停逻辑的 `reminderVisible`（及必要的稳定回调引用）；通过最新配置引用在触发提醒时读取 `randomTextEnabled`、`texts`、`reminderDurationMinutes` |
| pages/QuietHoursSettingsPage.tsx | 时段列表使用 `Collapse`；`defaultActiveKey` 为全部时段 `id`；每段 `label` 含序号、摘要、`enabled=false` 时辅助标识；顶部与「结束」表单项说明**支持跨午夜**（结束早于开始表示至次日）及左闭右开 |
| utils/quietHours.ts | `sanitizeQuietHourRange` 允许 `start>end`；`computeNextTriggerWithQuietHours` 基于时间戳判定命中与离开边界后加间隔；`formatQuietHourRangeLabel` 供折叠标题 |
| types/global.d.ts | `QuietHourRange` 注释标明跨午夜语义（可选，与共识一致） |
| utils/tauri.ts | 无新命令 |

与项目规范一致。

## 6. 交互流程设计

### 6.1 页面核心交互流程

- 用户修改主设置中的开机自启、锁屏、随机文案：配置立即持久化；**不**触发 `HomePage` 调度重算路径；主界面「下次提醒时间」标签与已设单次定时器保持一致。
- 用户修改间隔或免打扰：配置持久化后触发调度重算 → `updateNextTrigger`。
- 用户展开/折叠免打扰段：仅 UI 状态变化，不写存储；编辑与删除仍在展开面板内完成。

### 6.2 加载状态处理

与第二版一致。

### 6.3 异常状态处理

推迟迭代上限与第二版相同。

### 6.4 空状态处理

无时段时列表区为空；与第二版语义一致。

## 7. 全局状态管理设计

### 7.1 状态管理方案

React 本地状态；折叠默认由 `Collapse` 非受控 `defaultActiveKey` 初始化。

### 7.2 全局状态定义

`ReminderConfig` 单树不变。

### 7.3 状态更新规则

配置更新仍不可变；调度定时器生命周期与调度切片变更绑定。

## 8. 通用规范设计

### 8.1 样式设计规范

折叠容器可使用透明背景与无边框样式以融入卡片，仅用 AntD 公开 props，禁止全局样式污染。

### 8.2 性能优化规范

`items` 映射在段数 ≤20 下可接受；避免在每次键盘输入时重建无关全局状态。

### 8.3 兼容性适配规范

摘要格式化基于日内分钟索引与 24 小时展示；跨午夜段摘要为「开始-结束」数字对（如 22:00-06:00），不单独展示日期，由用户理解「次日」。
