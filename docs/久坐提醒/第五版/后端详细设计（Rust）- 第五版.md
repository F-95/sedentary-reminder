# 后端详细设计（Rust）-第五版

> **【已锁定】** 锁定日期：2026-05-09。本文件为久坐提醒第五版基线文档。

## 1. 设计概述

### 1.1 设计目标

保持第四版后端命令与运行时结构完全稳定；第五版为纯前端信息架构与状态展示增量，后端不感知枢纽、久坐子页、补水 next 镜像与 Card 标题文案。

### 1.2 设计约束

- 第五版迭代范围内不新增、不修改 Tauri 命令签名。
- `ReminderRuntimeState` 不因第五版做结构性扩展。
- 托盘菜单与镜像同步行为与第四版一致。

### 1.3 参考依据（系统总体设计、需求规格说明书）

《系统总体设计-第五版》《需求规格说明书-第五版》《后端详细设计（Rust）-第四版》。
