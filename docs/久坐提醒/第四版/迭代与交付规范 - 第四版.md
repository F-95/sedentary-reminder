# 迭代与交付规范-第四版

> **【已锁定】** 锁定日期：2026-05-09。本文件为久坐提醒第四版基线文档。

## 1. 迭代计划

### 1.1 版本迭代目标

交付久坐提醒第四版：**补水提醒（仅通知、可配置间隔、遵守免打扰）**；**免打扰默认折叠且新增仅展开新段**；v2 配置向后兼容；后端无签名变更。

### 1.2 迭代里程碑节点

| 里程碑 | 说明 |
|--------|------|
| M1 设计冻结 | 七份第四版文档归档 |
| M2 开发完成 | 前端实现、单元测试、Lint/构建通过 |
| M3 回归完成 | 第三版核心抽样 + 第四版增量用例通过 |
| M4 发布候选 | RC 构建与 Release Note |

### 1.3 任务拆分与排期

前端为主；后端冒烟确认无命令变更；测试维护 TC4 表。

## 2. 代码管理规范

### 2.1 分支管理规则

建议使用分支名：`久坐提醒-第四版`。

### 2.2 代码提交规范

提交信息包含：`久坐提醒-第四版`、变更关键词、对应设计章节（如「US4-P0-01」）。

### 2.3 代码合并与评审规则

至少一名评审；补水与久坐隔离须代码审查。

## 3. 构建与打包规范

### 5.3 回滚验证标准
