
### 用户可见

- 浅色 / 深色 / 跟随系统主题；主窗口标题栏随主题同步（Tauri）。
- 活动统计：近 7 日简报（嵌入主设置卡片标题下）、详情页按日/周/月/年查看久坐完成与补水提醒。
- 子页顶栏：左上仅图标返回（无障碍文案保留），右侧为页面标题。
- 主窗口默认约 520×760，**最小约 400×660**；枢纽区块顺序：久坐 / 补水 / 开机启动 / 主题模式 / 设置入口。

### 构建与发布

- 与标签 `v0.1.6` 对应之构建产物；详见 GitHub Releases。
- `package.json`、`Cargo.toml`、`tauri.conf.json` 版本对齐为 **0.1.6**。
