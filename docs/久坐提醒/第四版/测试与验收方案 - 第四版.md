# 测试与验收方案-第四版

> **【已锁定】** 锁定日期：2026-05-09。本文件为久坐提醒第四版基线文档。

## 1. 测试概述

### 1.1 测试范围

在第三版范围基础上增量：

- **补水**：开关、间隔边界、仅通知、免打扰内不发送、离开禁区后恢复、与久坐 next 解耦。
- **免打扰 UI**：默认全折叠、新增仅展开新段、删除后 activeKey 无残留、手动展开多段。
- **回归**：第三版 P0 调度边界与跨午夜推迟抽样。

### 1.2 测试目标

验证《需求规格说明书-第四版》US4-P0/P1/P2 可量化条目。

### 1.3 参考依据（需求规格说明书、系统总体设计、前后端详细设计）

《需求规格说明书-第四版》《系统总体设计-第四版》《前端详细设计（React）-第四版》《后端详细设计（Rust）-第四版》《测试与验收方案-第三版》。

## 3. 分级测试用例设计

### 3.1 P0核心用例（核心功能场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC4-P0-01 | 补水开、非免打扰 | 等待到达计划时刻 | 收到系统通知；无全屏提醒 |
| TC4-P0-02 | 补水开、当前在免打扰启用段内 | 观察计划时刻 | 不发补水通知 |
| TC4-P0-03 | 补水开 | 离开免打扰后下一计划点 | 按边界+N 分钟语义可再触发 |
| TC4-P0-04 | 久坐启用、next 已显示 | 仅改补水开关或间隔 | next 展示与镜像不变 |
| TC4-P0-05 | 免打扰页有多段 | 首次进入 | 全部折叠 |
| TC4-P0-06 | 免打扰页 | 点击新增 | 仅新段展开 |

### 3.2 P1重要用例（重要功能、边界场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
