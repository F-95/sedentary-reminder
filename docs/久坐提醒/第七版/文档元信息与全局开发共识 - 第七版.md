## 2. 全局技术栈规范

### 2.1 固定技术栈与版本号约束

与第六版一致：

- Tauri `2.0.0`
- React `18.2.0` / Vite `5.0.10` / TypeScript `5.2.2`
- Ant Design `5.12.0`
- @ant-design/plots `2.3.2`
- @tauri-apps/api `2.0.0`、通知插件 `2.0.0`
- Rust Edition `2021`

### 2.2 依赖版本管理规范

第七版不新增 npm / Cargo 依赖。

### 2.3 跨平台兼容要求

与第六版一致；窗口标题字符串为 UTF-8 中文，各平台标题栏需正常展示。

## 3. 全局代码规范

### 3.1 目录结构规范

第七版新增：`src/pages/AuthorBlurbPage.tsx`。配置变更：`src-tauri/tauri.conf.json` 主窗 `title`；根目录 `index.html` 的 `<title>`。

### 3.2 命名规则约束

与项目规范一致；页面文件大驼峰 `AuthorBlurbPage.tsx`；props 回调小驼峰 `onOpenAuthorBlurb`。

### 3.3 代码编写通用规范

- 随笔页为只读展示，不写 `localStorage`、不调用 `invoke`。
- 全局主题仍仅通过根 `ConfigProvider` 配置；随笔页禁止修改全局主题 token。

## 4. 全局权限与安全规范

### 4.1 接口权限通用规则

与第六版一致；第七版无新 Tauri 命令、无 capability 变更。

### 4.2 数据安全规范

随笔文案随前端静态资源分发；无新增本地持久化字段。

### 4.3 合规性要求

与第六版一致；第七版不采集用户阅读随笔的行为数据。

## 5. 需求优先级定义

### 5.1 P0 核心需求清单

- 启动后主窗口标题为 **久坐提醒（你的健康搭子）**（与《需求规格说明书-第七版》一致）。
- 枢纽可见 **作者的哔哔赖赖** 链式入口；进入子页后顶栏为规范 B 同构返回 + 标题；正文与署名文案符合需求锁定内容。

### 5.2 P1 重要需求清单

- 开发态浏览器标签页 `title` 与生产窗口标题一致（`index.html`）。
- 进入/离开 `author` 视图不影响第六版主题、统计与提醒调度。

### 5.3 P2 次要需求清单

- 随笔页在长文案下可滚动（与 `stats` 等子页外层 `overflowY: auto` 策略一致）。

## 6. 文档适用范围与边界说明
