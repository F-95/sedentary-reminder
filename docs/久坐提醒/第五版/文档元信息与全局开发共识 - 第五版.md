### 2.2 依赖版本管理规范

与第四版一致。

### 2.3 跨平台兼容要求

与第四版一致；枢纽展示时间与倒计时均基于客户端本地时间。

## 3. 全局代码规范

### 3.1 目录结构规范

延续项目结构强制规范；第五版变更集中于 `pages/ReminderSettingsPage.tsx`（枢纽）、新增 `pages/SedentaryReminderSettingsPage.tsx`、`pages/HomePage.tsx` 视图状态与补水镜像状态、时段文案纯函数可置于枢纽页模块内。

### 3.2 命名规则约束

与第四版一致；新增页面文件名：`SedentaryReminderSettingsPage.tsx`（大驼峰，与现有 `HydrationSettingsPage` 对齐）。

### 3.3 代码编写通用规范

- 久坐调度 `useEffect` 依赖边界与第四版一致；**禁止**因枢纽 UI 或时段文案刷新而扩大久坐调度依赖或误清定时器。
- 补水调度仍独立；`hydrationNextAt` 须与补水 `setTimeout` 所使用的目标时刻同源更新，避免展示与真实触发漂移。
- 主视图每秒刷新仅用于枢纽倒计时与 Card 标题时段文案；离开 `main` 视图须停止定时器，避免后台空转。
- 时段关怀文案须为**单行字符串**，不得含换行符；窄屏展示允许单行省略（ellipsis），禁止通过 Ant Design 深度选择器改 DOM。

## 4. 全局权限与安全规范

### 4.1 接口权限通用规则

第五版不新增 Tauri 命令；托盘仍仅同步三布尔（开机启动、启动提醒、提醒结束后锁屏）。

### 4.2 数据安全规范

配置仍仅存前端本地；不向远端上报；`update_next_trigger` 仍仅反映久坐 next。

### 4.3 合规性要求

与第四版一致。

## 5. 需求优先级定义

### 5.1 P0 核心需求清单

- 主界面（`main` 视图）首项为**开机启动**，文案与托盘「开机启动」一致；绑定 `autoStartEnabled`，行为与第四版一致（非调度项）。
- 枢纽页展示**久坐**与**补水**各自的「下次提醒时间」与「倒计时」；久坐数据与既有 `nextTriggerAt` 及全屏进行中状态一致；补水数据与补水调度链计算的下一触发时刻一致。
- 子页入口链接**纵向排列**，自上而下顺序为：**久坐提醒设置** → **补水提醒设置** → **免打扰时段设置**。
- 久坐专用表单（启用提醒、锁屏、间隔、活动倒计时、文案与随机开关）迁至独立页 **久坐提醒设置**，版式与补水页、免打扰页同构（Card、返回主界面）。

### 5.2 P1 重要需求清单

- Card **标题**为按**本地小时**分段的**单行**情绪关怀文案（无换行）；跨时段时随秒级时钟更新自动切换。
- 全屏久坐提醒进行中时，枢纽对久坐「下次时间/倒计时」展示约定状态（如「全屏提醒进行中」与倒计时占位），不得与补水展示逻辑耦合错误。

### 5.3 P2 次要需求清单

- 枢纽窄屏下单行标题省略号截断，无布局撑破。
- v2 配置无迁移需求（无新字段）。
