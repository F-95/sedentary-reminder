# 测试与验收方案-第一版

## 1. 测试概述

### 1.1 测试范围

覆盖久坐提醒第一版：前端调度与 UI、Tauri 命令与托盘联动、Windows 平台自启与锁屏、通知与铃声降级路径、扩展列举占位命令。

### 1.2 测试目标

验证需求规格说明书中 P0–P2 用户故事对应的可量化标准可被满足；识别阻塞发布的缺陷。

### 1.3 参考依据（需求规格说明书、系统总体设计、前后端详细设计）

《需求规格说明书-第一版》《系统总体设计-第一版》《后端详细设计（Rust）-第一版》《前端详细设计（React）-第一版》。

## 2. 测试环境与工具

### 2.1 测试环境配置要求

- 硬件：x86_64 Windows 10 或 Windows 11 物理机或虚拟机。
- 账号：标准用户权限（验证 HKCU 自启写入）。
- 显示：至少一台显示器；多显示器组合为 P1 验证推荐环境。

### 2.2 测试工具清单

- 系统自带通知设置面板（用于授权验证）。
- 秒表或系统时钟（人工比对触发误差）。
- 可选屏幕录制工具用于缺陷复现附件。

### 2.3 测试数据准备规范

- 提醒间隔建议使用短间隔（例如 2–3 分钟）以缩短等待；正式回归可使用 60 分钟级别做抽样。
- 文案数据准备包含：空行混合、单条、多条、含历史迁移过滤条目。

## 3. 分级测试用例设计

### 3.1 P0核心用例（核心功能场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC-P0-01 | 应用启动 | 启用提醒；设置间隔为最小可用整数 | 在间隔到达后触发全屏提醒视图 |
| TC-P0-02 | 提醒触发 | 观察窗口装饰与关闭控件状态 | 强制模式下关闭被拦截或不符合预期的关闭被拒绝 |
| TC-P0-03 | 提醒触发 | 点击开始活动并等待倒计时结束 | 会话结束后退出强制视图；锁屏开关关闭时不锁屏 |

### 3.2 P1重要用例（重要功能、边界场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC-P1-01 | 非强制模式 | 点击关闭主窗口 | 弹出或使用记忆策略执行托盘隐藏或退出 |
| TC-P1-02 | 启用提醒 | 触发调度后悬停托盘图标 | Tooltip 展示下次提醒摘要或未启用提示 |
| TC-P1-03 | Windows | 切换开机自启开关 | 注册表项创建或删除；重复关闭删除不报致命错误 |
| TC-P1-04 | Windows | 启用锁屏并完成活动 | 调用锁屏；关闭锁屏开关时不调用 |

### 3.3 P2次要用例（次要功能、异常场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC-P2-01 | 拒绝通知权限 | 临近触发 60 秒内 | 主流程仍可触发；通知可能缺失但不崩溃 |
| TC-P2-02 | 断网环境 | 触发提醒 | 铃声失败给出可读提示；界面仍可操作 |
| TC-P2-03 | 本地文案条目≤3 | 首次启动后等待默认标语加载 | 在后端可用时被替换为默认列表 |

## 4. 专项测试方案

### 4.1 功能测试方案

按照第 3 节用例执行；覆盖托盘菜单三项勾选与前端状态一致性。

### 4.2 性能测试方案

- 空闲 30 分钟观测 CPU 占用应在低水平波动范围；如出现异常占用记录为缺陷。

### 4.3 兼容性测试方案

- Windows 10 / 11 各至少一轮冒烟。
- 非 Windows 平台（若构建可用）：验证自启与锁屏返回不支持提示。

### 4.4 安全性测试方案

- 尝试在会话不匹配情况下结束活动：应被拒绝。
- 验证托盘事件不会触发未定义字段变更。

### 4.5 可用性测试方案

- 设置卡片字段直观性走查；文案输入支持多行。

## 5. 自动化测试方案

### 5.1 自动化测试范围

第一版以手工测试为主；可对纯函数配置迁移逻辑在未来迭代引入前端单元测试（不在本文档给出脚本）。

### 5.2 自动化测试工具选型

待定（迭代引入时在交付规范中锁定）。

### 5.3 自动化测试脚本设计规范

需遵循仓库 ESLint / Prettier / TypeScript 严格模式约束后方可合入。

## 6. 缺陷管理规范

### 6.1 缺陷分级标准

- **P0**：崩溃数据丢失或提醒完全不触发。
- **P1**：托盘严重不同步、锁屏误触发或无法退出强制模式。
- **P2**：文案边缘错误、通知缺失无提示。

### 6.2 缺陷报告规范

包含环境版本、复现步骤、期望与实际、附件日志或录屏。

### 6.3 缺陷闭环流程

发现 → 指派 → 修复 → 验证 → 关闭。

## 7. 测试准入准出标准

### 7.1 测试准入标准

- 可安装或可调试构建产物可用。
- 需求与设计文档第一版已归档。

### 7.2 测试准出标准

- P0 用例全部通过；P1 通过率不低于约定阈值（默认 100%）；P2 已知缺陷需登记缓解措施。

### 7.3 上线阻断规则

- 存在未关闭 P0；存在 Windows 平台锁屏或强制模式无法恢复的 P1。

## 8. 测试进度与里程碑

### 8.1 测试阶段划分

冒烟 → 全量功能 → 回归。

### 8.2 测试里程碑节点

构建就绪、首轮冒烟完成、预发布验证完成。

### 8.3 测试进度管控规则

每日记录执行覆盖率与缺陷统计。
