## 2. 全局技术栈规范

### 2.1 固定技术栈与版本号约束

- Tauri `2.0.0`
- React `18.2.0` / Vite `5.0.10` / TypeScript `5.2.2`
- Ant Design `5.12.0`
- **@ant-design/plots `2.3.2`**（统计图表，版本锁定）
- @tauri-apps/api `2.0.0`、通知插件 `2.0.0`
- Rust Edition `2021`

### 2.2 依赖版本管理规范

禁止在 `package.json` / `Cargo.toml` 对核心依赖使用通配符版本；图表库与 Ant Design 主版本须经过联调验证。

### 2.3 跨平台兼容要求

主题「跟随系统」依赖 `prefers-color-scheme`；统计按**客户端本地时区**分桶；Tauri 应用数据目录随平台变化，由 `app_data_dir` 解析。主窗口 **`tauri.conf.json`**：`minWidth` 400、`minHeight` 660（像素）。

## 3. 全局代码规范

### 3.1 目录结构规范

第六版新增/强化：`src-tauri/src/commands/stats.rs`；`src/components/SubSettingsTopBar.tsx`、`StatsBriefCard.tsx`；`src/pages/StatisticsPage.tsx`；`src/utils/themeMode.ts`、`statsBuckets.ts`；`src/vite-env.d.ts` 声明 `@ant-design/plots` 模块。

### 3.2 命名规则约束

与项目规范一致；统计事件类型使用 `snake_case` 字符串：`sedentary_completed`、`sedentary_triggered`、`hydration_notified`。

### 3.3 代码编写通用规范

- 全局主题仅通过根 `ConfigProvider` 的 `algorithm` 与 `token` 切换，禁止子组件覆盖 AntD 全局样式。
- 统计写入失败不得阻断提醒主流程；`invoke` 异常在前端静默或 `message` 提示由《前端详细设计》约定。
- 子页返回交互三页同构，禁止再使用 `Card.extra` 承载「返回主界面」。

## 4. 全局权限与安全规范

### 4.1 接口权限通用规则

新增 `core:window:allow-set-theme`（若默认能力集未覆盖）；统计命令随 `default` capability 注册，无单独远端鉴权。

### 4.2 数据安全规范

统计文件仅存本机应用数据目录，不上传；用户可通过删除应用数据清除统计。

### 4.3 合规性要求

与第五版一致；第六版不采集个人身份信息。

## 5. 需求优先级定义

### 5.1 P0 核心需求清单

- 主题三档可切换且持久化；跟随系统时系统主题变化后界面可更新。
- 子页 **规范 B**：首行左侧**仅图标**返回（`type="text"`，`aria-label`/`title` 含「返回主界面」）+ 页标题；三页一致。
- 久坐完成、久坐全屏触发、补水通知成功写入统计；枢纽**内嵌简报**可进入详情；详情支持 **日/周/月/年** 维度。

### 5.2 P1 重要需求清单

- 主枢纽视图在默认窗口高度下 **不出现纵向滚动条**（`main` 视图容器 `overflow: hidden`）；子页/统计详情允许区域内滚动。
- 窗口主题与有效亮暗主题对齐（`setTheme`）。

### 5.3 P2 次要需求清单

- 统计文件保留约 400 天自动裁剪；简报近 7 日柱状展示。
