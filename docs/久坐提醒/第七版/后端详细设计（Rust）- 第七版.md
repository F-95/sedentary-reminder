## 1. 设计概述

### 1.1 设计目标

第七版**不修改**后端业务：统计、提醒镜像与第五版以来命令集保持不变；随笔与窗口标题为前端与 Tauri 配置职责。

### 1.2 设计约束

- 不新增 `commands/*.rs` 文件；不修改 `stats.rs` 行为（除非缺陷修复单列版本）。
- `generate_handler!` 注册表与第六版一致。
