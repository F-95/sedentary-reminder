# 测试与验收方案-第五版

> **【已锁定】** 锁定日期：2026-05-09。本文件为久坐提醒第五版基线文档。

## 1. 测试概述

### 1.1 测试范围

在第四版范围基础上增量：

- **枢纽布局**：开机启动位置、久坐/补水双摘要、纵向链接顺序与跳转、Card 分时段单行标题。
- **久坐独立页**：字段完整性、返回主界面、配置持久化与久坐调度回归。
- **补水 next 镜像**：与定时触发一致性抽样、关闭补水时摘要清空。
- **主视图时钟**：仅 `main` 秒级刷新；离开 `main` 后无泄漏。
- **回归**：第四版 P0 补水与免打扰折叠、第三版以来久坐非调度项（开机启动不刷 next）抽样。

### 1.2 测试目标

验证《需求规格说明书-第五版》US5-P0/P1/P2 可量化条目。

### 1.3 参考依据（需求规格说明书、系统总体设计、前后端详细设计）

《需求规格说明书-第五版》《系统总体设计-第五版》《前端详细设计（React）-第五版》《后端详细设计（Rust）-第五版》《测试与验收方案-第四版》。

## 3. 分级测试用例设计

### 3.1 P0核心用例（核心功能场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC5-P0-01 | 默认进入 main | 检查纵向顺序与区块顺序 | 开机启动在最上；其下久坐摘要、补水摘要；链接自上而下为久坐、补水、免打扰 |
| TC5-P0-02 | main | 分别点三个链接再返回 | 进入对应页；返回均为 main |
| TC5-P0-03 | main | 打开久坐设置页 | 可见启用提醒、锁屏、间隔、活动倒计时、文案与随机；枢纽无上述表单项 |
| TC5-P0-04 | 补水开 | 对比枢纽「下次提醒时间」与内部下一拍（日志或断点） | 与补水 schedule 所用目标时刻同源；倒计时每秒变化 |
| TC5-P0-05 | 久坐启用、next 已显示 | 仅切换开机启动 | next 与镜像不因单独切换开机启动而错误跳变（同第三版以来约定） |

### 3.2 P1重要用例（重要功能、边界场景）

| 用例编号 | 前置条件 | 步骤摘要 | 期望结果 |
|----------|----------|----------|----------|
| TC5-P1-01 | main | 调整系统时间或等待跨小时边界 | Card 标题切换至对应时段单行文案；无换行符 |
| TC5-P1-02 | 久坐全屏提醒展示中 | 观察枢纽久坐区块 | 展示约定全屏中文案；不误读为久坐未启用（若久坐仍启用） |
| TC5-P1-03 | 进入久坐子页 | 观察 CPU/控制台 | 无每秒定时器日志（相对 main 行为） |
| TC5-P1-04 | 补水关 | 观察枢纽补水区 | 未启用类约定展示；`hydrationNextAt` 不驱动错误倒计时 |

## 6. 缺陷管理规范

### 6.1 缺陷分级标准

- **P0**：纵向顺序错误；久坐表单仍出现在枢纽；补水展示与真实触发系统性漂移；仅切开机启动导致久坐 next 错误重算；全屏时误显示未启用。
- **P1**：标题多行折行、子页仍跑秒级定时器、标题不随时段更新。
- **P2**：省略号策略缺失但窄屏可用。

### 6.2 缺陷报告规范
