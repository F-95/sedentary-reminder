# 测试与验收方案-第六版

> **【已锁定】** 锁定日期：2026-05-09。

## 1. 测试概述

### 1.1 测试范围

第六版新增：主题三档与系统联动、子页规范 B 顶栏、统计持久化与简报/详情、主枢纽滚动策略、窗口 `setTheme` 权限。

### 1.2 测试目标

验证功能与《需求规格说明书-第六版》P0/P1 一致；回归第五版枢纽与双通道调度无破坏。

### 1.3 参考依据（需求规格说明书、系统总体设计、前后端详细设计）

《需求规格说明书-第六版》《系统总体设计-第六版》《前端详细设计（React）-第六版》《后端详细设计（Rust）-第六版》。

## 2. 测试环境与工具

### 2.1 测试环境配置要求

Windows 10/11；Tauri 桌面运行包或 `npm run tauri dev`；可选变更系统浅色/深色主题。

### 2.2 测试工具清单

Vitest（`statsBuckets` 单元测试）、`cargo test`（stats 裁剪）、手动探索测试、开发者工具。

### 2.3 测试数据准备规范

清空或备份 `reminder_stats.jsonl`；准备多条不同 `kind` 与时间的事件用于聚合截图。

## 4. 专项测试方案

### 4.1 功能测试方案

按第 3 节用例执行；覆盖 `HomePage` 视图切换与 `invoke` 全链路。

### 4.2 性能测试方案

连续写入 500 次事件，记录单次 `record` 耗时主观可接受（无明显卡顿）。

### 4.3 兼容性测试方案

在 100%/125% 缩放下检查简报与顶栏不断裂。

### 4.4 安全性测试方案

确认统计文件仅位于应用数据目录，无网络请求。

### 4.5 可用性测试方案

3 秒内找到子页返回按钮（规范 B）。

## 5. 自动化测试方案

### 5.1 自动化测试范围

`statsBuckets` 纯函数；Rust `prune_events` 单元测试。

### 5.2 自动化测试工具选型

Vitest、cargo test。

### 5.3 自动化测试脚本设计规范

新增用例放在 `src/utils/statsBuckets.test.ts`；Rust 测试与模块同文件 `mod tests`。

## 6. 缺陷管理规范

### 6.1 缺陷分级标准

阻塞：无法完成活动或崩溃；严重：统计全丢；一般：主题不同步；轻微：文案。

### 6.2 缺陷报告规范

含复现步骤、期望/实际、版本、日志路径。

### 6.3 缺陷闭环流程

修复 → 回归对应 TC → 关闭。

## 7. 测试准入准出标准

### 7.1 测试准入标准

`npm run build`、`cargo build`、`npm test`、`cargo test stats` 通过。

### 7.2 测试准出标准

P0 用例 100% 通过；P1 无未修复阻塞/严重。

### 7.3 上线阻断规则

主题无法切换、统计写入导致崩溃、主流程提醒失效。

## 8. 测试进度与里程碑

### 8.1 测试阶段划分

单元 → 桌面手工 → 回归第五版。

### 8.2 测试里程碑节点

开发提交候选构建；测试出具通过清单。

### 8.3 测试进度管控规则

每日记录阻塞缺陷与风险。
