## 二、正文（公众号后台粘贴区）

你是不是也经常这样：早上坐下开会，中午外卖在工位解决，下午一抬头天都黑了。我们总说「忙完这阵就动一动」，结果身体最诚实——腰颈肩先抗议，注意力也越来越碎。

先说清楚一件事：**我不是医生**，下面只是公开资料里常被提到的「久坐相关风险」共识性描述——**连续静坐时间过长，与代谢、心血管、肌肉骨骼不适等问题的发生风险上升相关联**；对儿童、孕妇、基础疾病人群，风险讨论会更复杂。对大多数人来说，更可控、也更立竿见影的动作是：**把「长时间不动」切成一段段，让起身、拉伸、走动变成默认节奏**。

但知易行难。手机番茄钟会忘，手环会忽略，真正缺的是一个在电脑上**足够显眼、又不太羞辱你**的打断机制。

这就是我做的 **「久坐提醒（Sedentary Reminder）」**：一个跑在 **Windows** 上的桌面小工具，核心就一句话——**按你设定的间隔，到点提醒你站起来活动**。

【配图1：软件主界面 / 提醒设置——展示间隔、下次提醒时间等】

### 它怎么从「健康视角」帮你？

**1）把提醒从「想起来」变成「到点发生」**  
可配置提醒间隔（分钟）。时间一到进入提醒流程，减少「我再坐五分钟」的无声叠加。

**2）全屏提醒页：提高「被打断」的概率**  
用沉浸式全屏界面展示提醒文案和活动倒计时——不是角落小弹窗那种「一眼滑过」。

【配图2：全屏提醒界面——文案 + 活动倒计时】

**3）免打扰时段：不误伤睡眠与深度工作**  
支持多条免打扰时段（含跨午夜场景，例如 22:00 到次日 06:00）。在时段内自动跳过触发，和「下次提醒」计算联动，避免半夜被叫醒那种尴尬体验。

**4）系统通知：多场景补强**  
集成系统级通知，临近触发等场景也能给你一记「温柔拍肩」。

**5）自定义文案：让提醒更好坚持**  
支持多条提醒语，并可随机展示——你可以写点对自己有用的短句，把提醒从「唠叨」变成「你给自己的口令」。

**6）可选「活动结束后锁屏」**  
提醒流程结束可选择在 Windows 上锁定屏幕，适合你想强制离开工位去接杯水、走两分钟的场景（是否开启由你决定）。

**7）强制专注模式**  
在特定提醒状态下限制窗口被误关误跳过，减少手滑逃避。

**8）本地活动统计（仅本机、不上传）**  
可在应用内查看久坐完成等简报与详情（数据存于本机），方便你回顾「这周到底有没有动起来」——**不涉及云端上传**，隐私由你掌控。
